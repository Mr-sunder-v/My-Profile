
# Sunder V — Portfolio Site

A simple static site for a tester/QA engineer. Edit the text in `index.html` and add your links.

## How to run locally
1. Open this folder in VS Code.
2. Use the `Live Server` extension or simply double-click `index.html` to open in a browser.

## Deploy options
### GitHub Pages (Free)
1. Create a new GitHub repo named `sunder-portfolio`.
2. Push these files.
3. In **Settings → Pages**, choose `Deploy from a branch`, then select branch `main` and folder `/root`. If your repo keeps files at the root, it will publish automatically.
4. Your site will be available at `https://<your-username>.github.io/sunder-portfolio/`.

### Netlify (Free)
1. Create an account at Netlify.
2. Click **New site from Git**, connect your GitHub repo, and deploy.
3. Set a custom domain in Netlify Domain settings.

### Custom Domain
Buy a domain from a registrar (e.g., Namecheap) and point DNS to your host (GitHub Pages or Netlify). Add the domain in the host settings.

## Customizing
- Replace `assets/Sunder_V_Resume.pdf` with your resume file.
- Update email/LinkedIn/GitHub links in the Contact section.
- Edit colors in `assets/css/styles.css`.
